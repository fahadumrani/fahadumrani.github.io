# Fahad Umrani — Developer Profile

This repository contains the developer profile site for **Fahad Umrani**, the
creator of [Umrani AI](https://github.com/fahadumrani).

The site is intentionally lightweight and uses plain HTML, CSS and JavaScript.
It is deployed through GitHub Pages at:

**https://fahadumrani.devs.li**

## Umrani AI integration

Use the following URL for the **About Developer** button inside Umrani AI:

**https://fahadumrani.devs.li/#about-developer**

That deep link takes users directly to the developer introduction section.
